# PMHelper documentation

Documentation is organized by purpose. Start with the main project
[README](../README.md) for install and quick-start; use this tree for depth.

| Folder | What's in it |
|--------|--------------|
| [`guides/`](guides/) | User & feature how-to guides — CLI/API usage, risk, cost optimization, resource leveling, multi-objective, charter, quick references, and the server architecture. |
| [`reference/`](reference/) | Reference material — the educational feature list and the PM charts/KPIs/metrics comparison. |
| [`plans/`](plans/) | Design plans & specs — the EDU V1/V2 plans, the website plan, and agent/charter execution plans. **Historical:** these record what was *intended*, not what was built; paths they name may never have existed. Don't read them as current state. |
| [`reports/`](reports/) | Implementation summaries, validation/test reports, and phase completion reports (largely historical development records). |
| [`deployment/`](deployment/) | Deployment and packaging — production deployment, code signing, deployment alternatives. |
| [`releases/`](releases/) | Release notes per version. |
| [`sample_project/`](sample_project/) | A fully worked example project (charter, business case, WBS, schedule, registers…), with `_annotated` versions used for teaching. |
